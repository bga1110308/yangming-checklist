# A051 無紙化點班（試用版）

陽明交大永續課第二組的課堂試用作品：把 A051 病房六張紙本點班表（急救車、三班儀器、冷藏藥品、第 4 級管制藥品、醫用冰箱、月點班）做成手機點班網頁。

## 檔案在哪
| 檔案 | 放什麼 |
|---|---|
| `index.html` | 網頁外框 |
| `css/style.css` | 樣式 |
| `js/forms.js` | 六張表的品項與基本量（改品項只改這裡） |
| `js/store.js` | 所有雲端讀寫（Firebase），換資料庫只換這個檔 |
| `js/app.js` | 畫面：首頁、點班表單、護理長總覽、基本量設定 |
| `js/qr.js` | QR 碼：相機掃碼、產生貼紙 |
| `js/guide.js` | 使用說明彈窗內容 |
| `js/floor.js` | 平面圖：圖示位置、拖動（護理長才能調整） |
| `img/a051-floor.jpg` | A051 病房平面圖（從牆上消防逃生圖翻拍裁切） |

## 雲端
- Firebase 專案：`yangming-checklist`（擁有者 cicely.hi@gmail.com）
- 組員：點開連結自動匿名登入，可讀、可新增點班紀錄；紀錄送出後不能改
- 身分切換：右上角可切「護理師／護理長」。護理長才看得到總覽、能改基本量。
  試用版每個人都能自己切；正式版要改成由醫院帳號決定身分
- 擁有者：cicely.hi@gmail.com 用 Google 登入後才能清掉試用資料重來；要給別人看後台資料，從 Firebase 控制台把對方加成專案成員
- 安全規則在 Firebase 控制台 › Firestore › 規則

## 注意
- 只能放示範資料，不可輸入真實病人資料。
